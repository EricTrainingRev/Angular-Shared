Pipes

Built-in pipes

A pipe transforms a value for display in the template. You apply it with the pipe character (|): {{ '{{ value | pipeName }}' }}. Angular ships several built-in pipes for common formatting tasks.

Date pipe

Raw: {{ today() }}

Formatted: {{ today() | date:'short' }}

Uppercase and lowercase pipes

{{ 'hello' | uppercase }} and {{ 'WORLD' | lowercase }}

Currency pipe

{{ price() | currency:'USD' }}

Number pipe

{{ 3.14159 | number:'1.1-2' }}

Json pipe

{{ user() | json }}

When to use: reach for a built-in pipe to format dates, numbers, currency, or case without writing your own logic. They are declarative and keep the template readable.

Custom pipe

When a built-in pipe doesn't fit, you can write your own. The square pipe is a custom pipe that multiplies a number by itself.

The square of {{ baseNumber() }} is {{ baseNumber() | square }}.

When to use: write a custom pipe when you need to reuse the same transformation in several places — for example, a domain-specific format that no built-in pipe provides.

Pure vs impure pipes

A pipe is pure by default: it only re-runs when the input value's reference changes. An impure pipe re-runs on every change-detection cycle, so it catches in-place mutations that a pure pipe misses.

Click the button to add an item. The join pipe below is pure, so it won't update (the array reference stays the same). The joinImpure pipe is impure, so it re-runs and shows the new item.

Pure (join): {{ items() | join }}

Impure (joinImpure): {{ items() | joinImpure }}

When to use: default to pure pipes — they are efficient and correct for primitive values and immutable data. Only reach for an impure pipe when you must react to in-place changes inside a mutable object or array.
