Dynamic components

A dynamic component is one that is not hard-coded into a template but is chosen at runtime. The declarative way to do this is [ngComponentOutlet]: you hand it a component class and it instantiates and renders that component in place.

Below, the page holds a signal that picks which widget class should be shown. The buttons swap it, and ngComponentOutlet renders whichever class is active — the template never references either widget by name.
