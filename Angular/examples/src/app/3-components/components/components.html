Components

A component is a self-contained piece of UI — a template plus a class plus optional styles. A page is built by composing components: this page imports four children and renders them, then shows change detection and walks through the module story.

Change detection: OnPush + signals

Change detection is how Angular decides the DOM needs updating when data changes. Two strategies control how often a component is checked: Default (checked on every change-detection pass) and OnPush (checked only when an input reference changes, an event fires inside it, or a signal it reads is updated). This page uses OnPush.

What's happening: the counter is a signal, and the doubled/parity values are derived from it with computed(). Under OnPush — and this app's zoneless setup — updating that signal re-renders only the parts that read it, instead of checking the whole tree.

Why it matters: because of that, treat state immutably. Signals make this natural: rather than mutating a property on an existing object (which Angular may not notice), replace the whole value with a signal update.

Modules: NgModule vs standalone

Older Angular grouped components into NgModules — a container that declares which components belong to it, which other modules it needs, and which parts it exposes. Modern Angular (v15+) supports standalone components, which list their own dependencies in the imports array of @Component and act as their own mini-module. For new work, standalone is the default — no NgModule required.

NgModule (legacy)

  • declarations — the components, directives, and pipes that belong to this module.
  • imports — other modules this one needs (e.g. FormsModule).
  • exports — what other modules are allowed to use.
  • providers — services available within this module.

Standalone (modern)

  • Each component is its own mini-module.
  • Lists its dependencies in the imports of @Component.
  • No NgModule needed for most new work.

Understanding NgModules still matters because a great deal of existing code uses them — but newly written components are overwhelmingly standalone.
