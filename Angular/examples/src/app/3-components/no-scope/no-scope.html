View encapsulation: None

ViewEncapsulation.None disables scoping. Angular takes this component's styles and injects them straight into the document <head> as global CSS, so they apply to matching elements anywhere in the app — not just this component's own.

The panel below uses a class — .no-scope-box — that becomes global because encapsulation is None. Here its style is global: on the assembled page, another .no-scope-box element placed outside this component picks up this same coral styling, while the emulated demo box (a separate, scoped .demo-box) keeps its teal look.

This panel is styled from no-scope.css — and because encapsulation is None, the rule goes global.

A component reaches outside itself deliberately here. None is the right tool for global utility styles (a class you want to reuse anywhere) or for overriding a third-party component's styles.

Global utility: the .no-scope-highlight-box style also lives in no-scope.css. Because None makes it global, the page can drop this class on any element outside this component and get the highlight — proof the styles are app-wide.

When to use: None when you need global utility styles or to override a third-party component — and otherwise stick with the emulated default so your styles stay contained.
