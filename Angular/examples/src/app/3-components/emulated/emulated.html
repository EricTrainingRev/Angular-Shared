View encapsulation: Emulated

View encapsulation stops one component's CSS from leaking out and affecting the rest of the app. Emulated (the default) does this by having Angular add a unique attribute to each element in this component's template, then rewrite this component's style selectors to include that attribute — so they match only these elements.

The box below is styled by this component's own emulated.css. Because the encapsulation is emulated, that styling applies only here: another component that happened to use the same .demo-box class name would not pick up these rules.

This panel is styled from emulated.css — and stays scoped to just this component.

This is the contrast you'll see on the assembled page: the no-scope example uses the same .demo-box class name but with ViewEncapsulation.None, where its styles go global and will restyle even this box here.

When to use: the emulated default for nearly every component — it gives you isolation with no performance penalty. Reach for ViewEncapsulation.None only for genuine global utility styles or to override a third-party component.
