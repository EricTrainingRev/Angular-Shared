Products

Each product links to its detail route. The link bundles the product's id into the URL as a parameter: the array form [routerLink]="['/routing', 'product', product.id]" builds e.g. /routing/product/2.

    @for (product of products; track product.id) {
  • {{ product.name }} ${{ product.price }}
    • }

The detail page reads the :id parameter back out of the URL with ActivatedRoute and shows the matching product.
