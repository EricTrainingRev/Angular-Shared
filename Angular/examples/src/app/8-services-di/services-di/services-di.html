Services & Dependency Injection

A service is a class with one narrow job — here, owning shared to-do state. Dependency Injection (DI) is how Angular hands that service to any component that asks for it, instead of the component constructing it with new. This page injects a TaskStoreService and renders two children that expose the two service scopes: shared singleton vs component-scoped.

1. The shared task list — a root singleton

The page injects TaskStoreService with the modern inject() function. The store holds the list in a signal and derives the open-count with computed(). This page never works on a copy — it forwards the store's signals, so everything here reflects the single source of truth.
